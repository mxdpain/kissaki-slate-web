# Slate web

Static browser interface for Slate. Task access requires an approved Supabase login. No task records, passwords, or sessions are included.

Team members may restyle the interface. Changes to sync and the data model must be coordinated by the owner.

Updated 2026-10-27: shared permission-scoped Kissaki Notes lists, separate durable outbox, and conditional task writes preserving conflicting drafts. Original Supabase task IDs and lists remain unchanged.
